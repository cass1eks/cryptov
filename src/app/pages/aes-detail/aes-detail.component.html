SP-сеть AESнажми для пояснения
Round 1..Nr-1: SubBytes → ShiftRows → MixColumns → AddRoundKeyFinal Round: SubBytes → ShiftRows → AddRoundKey
SubBytes — нелинейная замена каждого байта через S-Box (16×16)
ShiftRows — циклический сдвиг строк матрицы состояния
MixColumns — умножение столбцов на матрицу в поле GF(2⁸)
AddRoundKey — XOR состояния с раундовым ключом
AES использует SP-сеть (Substitution-Permutation). В отличие от сети Фейстеля, обрабатывается весь блок целиком.
SubBytes (S-Box)нажми для пояснения
s'(i,j) = S[s(i,j)]S[x] = Affine(x⁻¹) в GF(2⁸)
s(i,j) — байт в позиции (строка i, столбец j)
S[x] — таблица замены Rijndael (256 значений)
x⁻¹ — мультипликативное обратное в поле GF(2⁸)
SubBytes — единственное нелинейное преобразование в AES, обеспечивающее стойкость к криптоанализу.
MixColumnsнажми для пояснения
[s'] = M × [s]M = [[02,03,01,01],[01,02,03,01],[01,01,02,03],[03,01,01,02]]
M — фиксированная матрица 4×4 над полем GF(2⁸)
× — матричное умножение в GF(2⁸)
MixColumns перемешивает байты в каждом столбце. Не выполняется в финальном раунде.
Режим CTRнажми для пояснения
Keystream = AES(Nonce || Counter)C(i) = M(i) ⊕ Keystream
Nonce — уникальное число (Number used ONCE)
Counter — счётчик, увеличивающийся для каждого блока
CTR — потоковый режим. Шифрование и расшифрование выполняются одинаково. Не требует padding.

КЛЮЧЕВЫЕ ПОНЯТИЯ

SP-сеть
Substitution-Permutation network — архитектура, в которой раунд состоит из слоя подстановки (S) и слоя перестановки (P).
S-Box
Substitution Box — таблица замены из 256 значений. Единственное нелинейное преобразование в AES, критичное для криптостойкости.
GF(2⁸)
Поле Галуа из 256 элементов. Все операции MixColumns выполняются в этом поле по модулю полинома x⁸+x⁴+x³+x+1.
Раундовый ключ
Ключ, уникальный для каждого раунда. Генерируется из исходного ключа алгоритмом Key Expansion с использованием RCON-констант.
